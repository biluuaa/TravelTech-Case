# TravelTech: мониторинг рейсов и перепланирование поездки

Кейс системного аналитика «Альфред, друг Бэтмена». Система отслеживает статусы рейсов, уведомляет о задержках и отменах, предлагает альтернативы с учётом багажа, виз и часовых поясов и обновляет общий план путешествия.

## Документ

[`Спецификация_мониторинг_рейсов.pdf`](Спецификация_мониторинг_рейсов.pdf) открывается прямо на GitHub, [`Спецификация_мониторинг_рейсов.docx`](Спецификация_мониторинг_рейсов.docx) содержит то же в Word. Полное проектное решение, 14 разделов:

1. Контекст, цель, границы, глоссарий
2. Вопросы к заказчику и допущения
3. Пользователи, роли, матрица прав
4. Ключевые проектные решения
5. Варианты использования
6. Процесс обработки сбоя
7. Требования: бизнес-требования, пользовательские истории с критериями приёмки, FR, NFR
8. Бизнес-правила
9. Взаимодействие: контекстная диаграмма, последовательность, состояния
10. Данные: концептуальная, логическая и физическая модели
11. API и события
12. Персональные данные
13. MVP, риски, открытые вопросы
14. Постановки задач: «Выбор альтернативы» (POST) и «Список альтернатив по сбою» (GET)
